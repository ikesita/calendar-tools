# 暦・日付ツール集

和暦の変換から月の満ち欠けまで、日付にまつわる計算をまとめた無料ツール集です。すべての計算はブラウザ内で完結し、入力内容は送信されません。和暦・干支・九星・月齢・厄年などの暦ツールに加え、2027年・2028年の日別カレンダーやイベントまでのカウントダウンも公開しています。

## 🌐 ライブサイト

**[https://ikesita.github.io/calendar-tools/](https://ikesita.github.io/calendar-tools/)**

## 主なツール

- **暦**：和暦・西暦 変換、干支・九星チェック、月齢・月の満ち欠け、誕生日ツール、厄年チェッカー
- **年齢・年度**：年齢早見表、生まれ年別 総合ページ、入学・卒業年度計算、年度・四半期計算、週番号計算
- **カウントダウン**：イベントまでのカウントダウン（クリスマス、お正月、ゴールデンウィーク、節分など）
- **カレンダー**：2027年・2028年 日別カレンダー（曜日・祝日・和暦・六曜つき）、2027年の祝日一覧、縁起の良い日一覧

## 使い方

ブラウザでライブサイトを開き、使いたいツールを選ぶだけです。インストールや会員登録は不要です。

## 注意事項

表示内容はあくまで目安です。祝日は法改正等により変更される場合がありますので、正式な情報は内閣府の発表等でご確認ください。
